# Security Policy

## Reporting a Vulnerability

If you discover a security issue with Sandbox AI, please open a GitHub issue
at https://github.com/cy/sandbox-ai/issues with the `security` label, or contact
the maintainers privately.

This project is a fork of [opencode](https://github.com/anomalyco/opencode).
For vulnerabilities specific to upstream opencode behavior, please also report
to the upstream project.
